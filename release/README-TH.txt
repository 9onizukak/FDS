FDH 1.0.4 — Windows 64-bit

ติดตั้งด้วย FDH-Setup-1.0.4.exe จากนั้นเปิด FDH จาก Start Menu
ไม่ต้องติดตั้ง Python และไม่ต้องใช้สิทธิ Administrator

การตั้งค่าครั้งแรก
1. กด "ตั้งค่าการเชื่อมต่อ" ในโปรแกรม
   ปุ่มรุ่นใหม่ชื่อ "ตั้งค่า API / การเชื่อมต่อ"
   เลือก UAT (ทดสอบ) หรือ PRODUCTION (ส่งจริง) และตรวจสอบ URL ก่อนบันทึก
   การเปลี่ยนโหมด API มีผลทันที ไม่ต้องเปิดโปรแกรมใหม่
   Base URL ใส่ได้ทั้งโดเมน หรือ URL ถึง dataset หากหน่วยงานกำหนดเส้นทาง API อื่น
   ส่วนบัญชีและฐานข้อมูล ให้กด "แก้ไขบัญชี / รหัสผ่าน / ฐานข้อมูล"
2. ตรวจสอบค่าตั้งต้นของบัญชี FDH และการเชื่อมต่อ HOSxP แล้วเติมรหัสผ่านใน Notepad
   ใช้บัญชีฐานข้อมูลแบบ read-only เท่านั้น
3. บันทึกไฟล์ แล้วปิดและเปิด FDH ใหม่
4. เลือกวันที่ ค้นหา และตรวจสอบรายการก่อนกดส่ง

ไฟล์ตั้งค่า: %LOCALAPPDATA%\FDH\.env
ประวัติการส่ง: %LOCALAPPDATA%\FDH\send_history.jsonl
ค่าเริ่มต้นเป็น UAT สามารถเลือก PRODUCTION ได้ในหน้าตั้งค่า API
ประวัติและสถานะการส่งแยกตามโหมด ประวัติรุ่นเดิมที่ยังไม่มีโหมดถือเป็น UAT
ขณะค้นหา ส่ง หรือตรวจสถานะ ต้องรอให้งานเสร็จก่อนเปลี่ยนโหมด
Production ใช้ URL ตามเอกสารเป็นค่าตั้งต้น แต่เส้นทาง dataset ตอบ 404 ขณะตรวจ
หากหน่วยงานแจ้ง URL ใหม่ ให้แก้ Base URL ในหน้าตั้งค่า API
ตัวติดตั้งไม่รวมรหัสผ่านหรือข้อมูลผู้ป่วย
อัปเดตและถอนการติดตั้งจะเก็บไฟล์ตั้งค่าและประวัติไว้
เมื่ออัปเดต โปรแกรมเพิ่มตัวแปรที่ยังไม่มี โดยไม่เปลี่ยนค่าที่เคยตั้งไว้

แบบ Portable: แตก FDH-Portable-1.0.4.zip แล้วเปิด FDH\FDH.exe
ต้องเก็บโฟลเดอร์ _internal ไว้ด้วย ใช้ไฟล์ตั้งค่าตำแหน่งเดียวกับรุ่นติดตั้ง

ตราสาธารณสุข: https://cco.moph.go.th/cco24/logo.html
ไฟล์นี้ยังไม่ได้ลงลายเซ็นดิจิทัล

อัปเดตโปรแกรมจาก GitHub
โปรแกรมตรวจสอบรุ่นใหม่เมื่อเปิดและทุก 1 ชั่วโมง หากเปิดอัปเดตอัตโนมัติ
แถบด้านล่างแสดงรุ่นปัจจุบัน มีปุ่มตรวจสอบอัปเดตและตัวเลือกปิดอัปเดตอัตโนมัติ
ดาวน์โหลดและตรวจ SHA-256 ก่อนติดตั้ง รอให้งานค้นหา/ส่ง/ตรวจสถานะเสร็จและปิดหน้าตั้งค่า API ก่อนติดตั้ง
โปรแกรมจะปิดและเปิดใหม่หลังอัปเดต การตั้งค่าและประวัติการส่งจะยังอยู่
แบบ Portable จะใช้ตัวติดตั้งอัปเดตลงโฟลเดอร์เดิมและลงทะเบียนเป็นโปรแกรมที่ติดตั้งแล้ว
โฟลเดอร์โปรแกรมต้องเขียนได้ หากอัปเดตไม่สำเร็จดู log ที่ %LOCALAPPDATA%\FDH\updates
